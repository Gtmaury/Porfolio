# Mauricio González — Portafolio Profesional

Este es el repositorio oficial de mi portafolio profesional como **Desarrollador Frontend**. Diseñado con una estética moderna, limpia y minimalista, el sitio web muestra mi stack técnico, habilidades secundarias, certificaciones obtenidas y mis proyectos destacados.

## 🚀 Características del Proyecto

- **Estructura Modular Profesional**: Código limpio y separado en módulos (`index.html`, `css/style.css`, `js/main.js`) bajo estándares modernos de desarrollo.
- **Internacionalización Dinámica**: Soporte bilingüe completo (Español e Inglés) auto-detectable mediante el idioma del navegador y persistido a través de `localStorage`.
- **Diseño Responsivo Avanzado**: Totalmente optimizado para una visualización premium en ordenadores, tablets y teléfonos de cualquier tamaño, con alineamiento y tamaños de botones responsivos adaptados al viewport.
- **Interacciones Premium**:
  - Efecto de grano de ruido de fondo sutil.
  - Animaciones de hover con gradientes y micro-transiciones suaves en tarjetas y botones.
  - Carga diferida con animaciones de entrada (`fade-in`) basadas en la API nativa `IntersectionObserver`.
- **Accesibilidad y SEO**: Uso estricto de HTML5 semántico y mejores prácticas para indexación de motores de búsqueda.

## 🛠️ Stack Tecnológico

- **HTML5**: Estructura semántica, accesibilidad y maquetación web.
- **CSS3**: Estilos adaptativos utilizando CSS Grid, Flexbox y animaciones avanzadas (sin frameworks externos como Tailwind, manteniendo flexibilidad y control absoluto).
- **JavaScript (ES6+)**: Lógica pura para manipulación del DOM, cambio de idioma en tiempo real y observables de scroll.
- **Fuentes**: Google Fonts (Syne para titulares expresivos, DM Sans para legibilidad de cuerpo de texto).

## 💻 Ejecución Local

Para visualizar el proyecto de forma local, no necesitas dependencias ni compiladores complejos. Simplemente clona este repositorio y abre el archivo `index.html` en tu navegador, o utiliza una extensión de servidor local como **Live Server** en VS Code:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Gtmaury/Porfolio.git
   ```
2. Accede a la carpeta:
   ```bash
   cd Porfolio
   ```
3. Ejecuta con tu servidor local preferido.
